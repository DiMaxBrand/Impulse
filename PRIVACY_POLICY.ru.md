## 1. Коротко

- «Импульс» — клиент мессенджера на открытом протоколе XMPP. Разработчик **является оператором XMPP-сервера `on-chat.ru`**: аккаунты, которые вы создаёте в приложении, регистрируются именно на нём, и данные этих аккаунтов хранятся на этом сервере.
- Сервер работает на программном обеспечении Prosody и размещён на арендованном виртуальном сервере: **[ХОСТИНГ-ПРОВАЙДЕР, СТРАНА РАЗМЕЩЕНИЯ]**.
- По умолчанию в приложении включено **сквозное шифрование OMEMO**: содержимое таких сообщений Разработчик прочитать не может. Шифрование можно отключить; тогда содержимое сообщений на сервере хранится в открытом виде и технически доступно администратору сервера (подробнее — в разделе 3).
- В приложении нет рекламы, аналитики и трекеров.
- Исходный код приложения открыт: https://github.com/DiMaxBrand/Impulse — всё, что описано ниже в части работы приложения, можно проверить.

## 2. Сервер on-chat.ru: какие данные на нём хранятся

Если вы создали аккаунт в приложении (то есть на `on-chat.ru`), на сервере хранятся:

- имя пользователя (адрес вида `имя@on-chat.ru`) и данные для входа;
- список ваших контактов и подписок;
- имя и аватар профиля, если вы их задали;
- сообщения: очередь недоставленных сообщений и архив сообщений на сервере — **[СРОК ХРАНЕНИЯ АРХИВА СООБЩЕНИЙ]**;
- загруженные вами файлы (фото, видео, документы, голосовые сообщения) — **[СРОК ХРАНЕНИЯ ЗАГРУЖЕННЫХ ФАЙЛОВ]**;
- групповые чаты и каналы, которые вы создали или в которые вошли;
- технические журналы сервера (IP-адрес, время подключения): **[ВЕДУТСЯ ЛИ ЖУРНАЛЫ И КАК ДОЛГО ХРАНЯТСЯ]**.

Эти данные нужны только для работы мессенджера. Разработчик не использует их для рекламы, не продаёт и не передаёт третьим лицам.

Если вы подключили к приложению аккаунт на **другом** сервере, оператором этого сервера является третье лицо, а не Разработчик; его данные обрабатываются по правилам этого оператора.

## 3. Шифрование и кто может прочитать сообщения

- **OMEMO включено по умолчанию.** Содержимое сообщений шифруется на вашем устройстве и расшифровывается только на устройствах собеседников. Сервер, включая администратора, получает и хранит только зашифрованные данные и прочитать содержимое не может.
- **Шифрование можно отключить** — для всех чатов в настройках приложения или для отдельного чата. Для сообщений без шифрования действует следующее: они передаются по соединению, защищённому TLS, но **хранятся на сервере в читаемом виде**, поэтому у администратора сервера существует техническая возможность их прочитать. Мы ценим приватность пользователей: Разработчик не читает переписку, не использует её и не передаёт третьим лицам.
- Метаданные (кто, кому и когда пишет, когда вы в сети) серверу видны независимо от шифрования содержимого.
- Если вам важна конфиденциальность переписки, не отключайте шифрование.

## 4. Что хранится на вашем устройстве

В закрытой от других приложений области памяти приложения хранятся: данные ваших аккаунтов (адрес XMPP и пароль для входа), сообщения и вложения, список контактов, ключи шифрования (OMEMO, OpenPGP) и настройки приложения. Эти данные удаляются при удалении приложения или очистке его данных. Резервную копию приложение создаёт только по вашей команде; файл копии сохраняется там, куда вы его укажете.

## 5. Что уходит с устройства и кому

**5.1. XMPP-сервер.** Приложение подключается к серверу вашего аккаунта (по умолчанию `on-chat.ru`). На сервер передаются данные для входа, ваши сообщения, статусы присутствия, набор текста, загружаемые файлы и технические метаданные соединения. Соединение защищено TLS. Сообщения, адресованные пользователям других серверов, получает сервер получателя; он не принадлежит Разработчику.

**5.2. Канал новостей.** При первом подключении аккаунта приложение автоматически добавляет официальный канал новостей `news@conference.on-chat.ru` на сервере Разработчика. Канал можно покинуть в любой момент; повторно он добавляться не будет.

**5.3. Звонки.** Аудио- и видеозвонки используют WebRTC. Для установления соединения используются STUN/TURN-серверы, предоставляемые сервером вашего аккаунта. При прямом соединении собеседник может узнать ваш IP-адрес.

**5.4. Прямая передача файлов.** При передаче файла напрямую между устройствами собеседнику виден ваш IP-адрес.

**5.5. Уведомления UnifiedPush.** Если вы настроили доставку уведомлений через UnifiedPush, служебный сигнал о новых сообщениях проходит через push-сервер `up.conversations.im`, который принадлежит третьему лицу. Он получает адрес вашего устройства для доставки сигнала и сам факт сигнала. **[ПОДТВЕРДИТЕ: сервер on-chat.ru не передаёт текст сообщений в push-уведомлениях]**

**5.6. Проверка и загрузка обновлений.** Приложение обращается к GitHub (`api.github.com`, `github.com`), чтобы узнать о новых версиях и скачать их. GitHub видит ваш IP-адрес и версию приложения. Автоматическую проверку можно отключить: Настройки → Обновления → «Автопроверка обновлений».

**5.7. Карты.** При отправке или просмотре геопозиции приложение загружает фрагменты карты OpenStreetMap; сервер карт видит ваш IP-адрес и запрошенный участок.

**5.8. Поиск каналов.** Если вы пользуетесь поиском публичных каналов, поисковый запрос отправляется на сервис `search.jabber.network`, который принадлежит третьему лицу.

**5.9. Отчёты об ошибках.** После сбоя приложение спрашивает, отправить ли отчёт. Только если вы нажмёте «Отправить сейчас», отчёт (версия приложения, производитель и модель устройства, время, технический протокол ошибки) уходит обычным, не зашифрованным сообщением с вашего аккаунта на адрес поддержки `support@on-chat.ru` на сервере Разработчика; адрес вашего аккаунта при этом виден получателю. Отключить: Настройки → Конфиденциальность → «Отправлять отчёты о сбоях».

**5.10. Ссылки.** При переходе по ссылке из сообщения или справки она открывается во внешнем приложении или браузере, и дальнейшая обработка данных определяется ими.

## 6. Разрешения Android и зачем они нужны

| Разрешение | Для чего |
|---|---|
| Интернет, состояние сети и Wi-Fi | подключение к серверу |
| Камера | фото, видео, сканирование QR-кодов, видеозвонки |
| Микрофон | голосовые сообщения и звонки |
| Геолокация | только когда вы сами отправляете своё местоположение |
| Уведомления | оповещения о сообщениях и звонках |
| Службы переднего плана, запуск при загрузке, исключение из экономии батареи, WAKE_LOCK | поддерживать соединение и принимать сообщения в фоне |
| Полноэкранные уведомления, окно поверх других, управление звонками | показ входящих звонков |
| Bluetooth | работа с гарнитурой во время звонков |
| Доступ к файлам (на старых версиях Android) | отправка и сохранение вложений |
| Установка пакетов | установка скачанных вами обновлений приложения |
| Вибрация, настройки звука | сигналы и звук звонков |

Приложение **не запрашивает доступ к вашей телефонной книге**.

## 7. Чего приложение не делает

Приложение не содержит рекламы, рекламных и аналитических SDK, не отслеживает ваши действия, не передаёт данные третьим лицам в коммерческих целях и не создаёт профиль пользователя.
