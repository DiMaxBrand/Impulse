## 1. Коротко

- «Импульс» — клиент мессенджера на открытом протоколе XMPP. У Разработчика **нет собственных серверов**, на которых хранились бы ваши аккаунты, сообщения, файлы или контакты.
- Разработчик **не собирает, не получает и не хранит** ваши персональные данные, не показывает рекламу, не использует аналитику и трекеры.
- Ваши сообщения передаются на XMPP-сервер, который **вы выбрали сами**, и хранятся на вашем устройстве.
- Исходный код приложения открыт: https://github.com/DiMaxBrand/Impulse — всё, что написано ниже, можно проверить.

## 2. Что хранится на вашем устройстве

В закрытой от других приложений области памяти приложения хранятся: данные ваших аккаунтов (адрес XMPP и пароль для входа), сообщения и вложения, список контактов, полученный с сервера, ключи шифрования (OMEMO, OpenPGP) и настройки приложения.

Эти данные остаются на устройстве. Они удаляются при удалении приложения или очистке его данных. Резервную копию приложение создаёт только по вашей команде; файл копии сохраняется там, куда вы его укажете.

## 3. Что уходит с устройства и кому

**3.1. XMPP-сервер.** Для работы мессенджера приложение подключается к XMPP-серверу, адрес которого вы указываете при добавлении аккаунта. На сервер передаются: данные для входа, ваши сообщения, статусы присутствия, набор текста, загружаемые файлы и технические метаданные соединения. Сервер получателя получает сообщения, адресованные его пользователям. Операторами серверов являются третьи лица, а не Разработчик; обработка данных на сервере регулируется их собственными правилами. Соединение с сервером защищено TLS.

**3.2. Сквозное шифрование.** Если включено шифрование OMEMO или OpenPGP, содержимое сообщений недоступно серверу. Метаданные (кто, кому и когда пишет) серверу по-прежнему видны.

**3.3. Звонки.** Аудио- и видеозвонки используют WebRTC. Для установления соединения используются STUN/TURN-серверы (как правило, вашего XMPP-сервера). При прямом соединении собеседник может узнать ваш IP-адрес.

**3.4. Прямая передача файлов.** При передаче файла напрямую между устройствами (Jingle) собеседнику становится виден ваш IP-адрес.

**3.5. Проверка и загрузка обновлений.** Приложение обращается к GitHub (api.github.com, github.com), чтобы узнать о новых версиях и скачать их. GitHub при этом видит ваш IP-адрес и версию приложения. Автоматическую проверку можно отключить: Настройки → Обновления → «Автопроверка обновлений». Кнопка «Проверить сейчас» работает только по вашему нажатию.

**3.6. Карты.** При отправке или просмотре геопозиции приложение загружает фрагменты карты OpenStreetMap; сервер карт видит ваш IP-адрес и запрошенный участок карты.

**3.7. Отчёты об ошибках.** После сбоя приложение спрашивает, отправить ли отчёт. Только если вы нажмёте «Отправить сейчас», отчёт (версия приложения, производитель и модель устройства, время, технический протокол ошибки) уходит обычным, не зашифрованным XMPP-сообщением с вашего аккаунта на адрес поддержки **support@on-chat.ru**; получатель при этом видит адрес вашего аккаунта. Отключить: Настройки → Конфиденциальность → «Отправлять отчёты о сбоях».

**3.8. Ссылки.** При переходе по ссылке из сообщения она открывается во внешнем приложении или браузере, и дальнейшая обработка данных определяется ими.

## 4. Разрешения Android и зачем они нужны

| Разрешение | Для чего |
|---|---|
| Интернет, состояние сети и Wi-Fi | подключение к XMPP-серверу |
| Камера | фото, видео, сканирование QR-кодов, видеозвонки |
| Микрофон | голосовые сообщения и звонки |
| Геолокация | только когда вы сами отправляете своё местоположение |
| Уведомления | оповещения о сообщениях и звонках |
| Службы переднего плана, запуск при загрузке, исключение из экономии батареи, WAKE_LOCK | поддерживать соединение и принимать сообщения в фоне |
| Полноэкранные уведомления, окно поверх других, управление звонками | показ входящих звонков |
| Bluetooth | работа с гарнитурой во время звонков |
| Доступ к файлам (на старых версиях Android) | отправка и сохранение вложений |
| Установка пакетов | установка скачанных вами обновлений приложения |
| Вибрация, настройки звука | сигналы и звук звонков |

Приложение **не запрашивает доступ к вашей телефонной книге**.

## 5. Чего приложение не делает

Приложение не содержит рекламы, рекламных и аналитических SDK, не отслеживает ваши действия, не передаёт данные третьим лицам в коммерческих целях и не создаёт профиль пользователя.

## 6. Хранение и удаление данных

Разработчик не хранит данные пользователей, поэтому удалять у Разработчика нечего. Чтобы удалить данные на устройстве — удалите аккаунт в приложении или очистите данные приложения. Чтобы удалить данные на XMPP-сервере — обратитесь к оператору сервера или воспользуйтесь средствами удаления аккаунта, которые он предоставляет.

## 7. Дети

Приложение не ориентировано на детей. Разработчик не собирает сведения о возрасте пользователей.

## 8. Запросы государственных органов

Разработчик не имеет доступа к содержимому переписки, спискам контактов и данным аккаунтов пользователей и не хранит их, поэтому не располагает данными, которые мог бы предоставить. Сведения о пользователях могут находиться у операторов XMPP-серверов; с такими запросами следует обращаться к ним.

## 9. Изменения политики

При изменении политики новая редакция публикуется по тому же адресу с новой датой вступления в силу.
